# Cinnamon-Delight-Dark

Dark counterpart of **Cinnamon-Delight** used by CaramOS dark mode.

Generated by `packages/caramos-ota/tools/build-delight-dark-theme.py` from **Mint-Relaxed** by DrMcC0y
(https://github.com/DrMcC0y/Mint-Relaxed.git, commit `01c6cb9dc1679b9ecd76fdca27ab6ed99da6dffa`), the dark edition of the same design:

- every grey is re-tinted to Cinnamon-Delight's mauve hue at the same lightness;
- content, sidebar, toolbar band, buttons and borders get the same lightness steps as Delight;
- accent and status colours are unchanged;
- the CaramOS three-dock panel CSS is appended in its dark colours.
